# Lane Legion TD v0.1
Original mobile auto-battler/tower-defense prototype inspired by the general wave-defense genre.

## Play
- Select Guard, Gunner or Crusher at the bottom.
- Tap an empty grid cell during BUILD to buy/place it.
- START launches the next wave immediately; otherwise the timer starts it.
- Towers attack automatically. Survive as many waves as possible.
- Clearing a wave pays income; kills also award gold.

## Run
Open `project.godot` with Godot 4.x and press F6/F5.

## Android
Create an Android export preset in Godot and export an APK. Current Godot Android documentation recommends JDK 17 for manual desktop setup; recent versions can also set up Android/Java SDK support from the editor.
